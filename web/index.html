Detection Capabilities

Powerful Security Features

Advanced detection techniques working together to identify even the most sophisticated phishing attempts.

URL Heuristic Analysis

Detects suspicious URL patterns including typosquatting, IP-based hosting, excessive subdomains, and deceptive path structures.

DOM Content Scanning

Analyzes page structure, form actions, embedded scripts, and suspicious HTML elements that mimic legitimate login pages.

Threat Classification

Categorizes detected threats by attack type — credential harvesting, brand impersonation, social engineering, and more.

SSL/TLS Verification

Checks certificate validity, issuer reputation, and encryption protocols to identify sites using deceptive security indicators.

Real-Time Scanning

Instant analysis with results in seconds. Every scan performs a fresh, live evaluation of the target URL, and each result is saved to the MySQL scan history.

Rate Limiting & Security

Built-in API rate limiting, security headers, and input sanitization to protect the detection engine from abuse.
